- نماذج تواصل تفاعلية

- CSS3 (مع CSS Variables)
- JavaScript (Vanilla JS)
- Font Awesome Icons
- Google Fonts (Tajawal)
- AOS Animation Library

## 🚀 رفع الموقع على GitHub Pages

### الطريقة الأولى: عبر GitHub Desktop

1. **قم بتثبيت GitHub Desktop**
   - حمّل البرنامج من: https://desktop.github.com/

2. **أنشئ Repository جديد**
   - افتح GitHub Desktop
   - اذهب إلى: File → New Repository
   - اسم الـ Repository: `portfolio` (أو أي اسم تريده)
   - اختر مجلد Portfolio كمكان للـ Repository
   - اضغط Create Repository

3. **ارفع الملفات**
   - GitHub Desktop سيكتشف جميع الملفات تلقائياً
   - في خانة Summary اكتب: "Initial commit - Portfolio website"
   - اضغط "Commit to main"
   - اضغط "Publish repository" في الأعلى
   - تأكد من إزالة علامة ✓ من "Keep this code private" (لجعله عام)
   - اضغط Publish Repository

4. **فعّل GitHub Pages**
   - افتح الـ Repository على GitHub.com
   - اذهب إلى: Settings → Pages
   - تحت "Source" اختر: `main` branch
   - اضغط Save
   - انتظر دقيقة وسيظهر رابط موقعك!

### الطريقة الثانية: عبر Git Command Line

```bash
# 1. انتقل لمجلد المشروع
cd c:\Users\Acer\Portfolio

# 2. ابدأ Git Repository
git init

# 3. أضف جميع الملفات
git add .

# 4. عمل Commit أول
git commit -m "Initial commit - Portfolio website"

# 5. أنشئ Repository على GitHub.com أولاً ثم:
git remote add origin https://github.com/YOUR-USERNAME/portfolio.git

# 6. ارفع الملفات
git branch -M main
git push -u origin main

# 7. فعّل GitHub Pages من Settings → Pages
```

### الطريقة الثالثة: الرفع المباشر عبر GitHub.com

1. اذهب إلى: https://github.com/new
2. أنشئ Repository جديد باسم `portfolio`
3. اجعله Public
4. لا تضيف README أو .gitignore
5. بعد إنشاء الـ Repository:
   - اضغط "uploading an existing file"
   - اسحب جميع ملفات Portfolio (index.html, style.css, script.js)
   - اضغط Commit changes
6. اذهب إلى Settings → Pages
7. اختر main branch واضغط Save
